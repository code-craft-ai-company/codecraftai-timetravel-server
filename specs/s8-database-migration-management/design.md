# S8.1 — Database Migration Management: Design

## Module Layout
```
source/packages/automojo/timetravelserver/
    migrations/
        env.py
        versions/
            <auto-generated migration scripts>
    alembic.ini
```

### Integration
- Alembic configured with SQLAlchemy `Base.metadata`.
- CLI commands: `alembic upgrade head`, `alembic downgrade -1`, `alembic revision --autogenerate`.
- Startup version check in server initialization.

### Dependencies
- S0.1 (ORM models, Base metadata), Alembic library
