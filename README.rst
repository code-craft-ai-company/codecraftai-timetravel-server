==========================
automojo-timetravel-server
==========================

Automation Mojo - Time Travel Server

Overview
========
automojo-timetravel-server is a core component of the Automation Mojo technology stack. It provides robust, reusable foundation code designed to enable and orchestrate complex software automation tasks.

Installation
============
Using Poetry:

.. code-block:: bash

    poetry add automojo-timetravel-server

Development
===========
This repository provides a standard Poetry environment.

1. Activate virtual environment:
   Run `poetry shell` and `poetry install`
2. Test Execution:
   Run `poetry run pytest`
